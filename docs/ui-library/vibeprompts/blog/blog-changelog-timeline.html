Changelog

We ship on Tuesdays. Breaking changes get a month of notice.

17 Aug 2026

v4.2.0

Per-branch environment variables

New Improved

Variables can now be scoped to a branch pattern, so preview builds stop borrowing production credentials by accident.

  • → Pattern matching supports globs, e.g. release/*
  • → Secrets inherit from the default set unless overridden
  • → The variable editor now shows which builds used a value last

5 Aug 2026

v4.1.0

Runner images split into layers

Improved Breaking

Base tooling and language runtimes now live in separate layers, which cuts a cold runner start from 41 to 12 seconds.

Breaking: pinned image digests

Anything pinning runner@sha256:… must repin before 1 October. Tag-based references keep working.

22 Jul 2026

v4.0.3

Cache keys no longer collide across packages

Fixed

In monorepos, two packages with identical lockfile hashes could share a cache entry. Keys now include the workspace path.

  • → Existing entries are invalidated once, on first build
  • → Restore logs now print the full key that matched
