Written answers

Which browsers do you support?

The current and previous major versions of Chrome, Firefox, Safari and Edge. Older versions keep working but stop receiving fixes.

Can I embed a report in our intranet?

Yes, with a signed embed token so the viewer inherits the right access rules.

POST /v1/reports/rep_8f21/embed-token
Is there a limit on scheduled reports?

Fifty per workspace on Team and unlimited on Scale. Each schedule can have up to 200 recipients.

Do you have a dark theme?

It follows your system setting by default, and can be pinned per person in profile settings. Exported PDFs stay light regardless.

Can I use it on a tablet?

Viewing and commenting work well. Building reports needs a pointer, so we would not recommend it for authoring.
