Accessibility

Usable without a mouse, without colour, without hurry

We target WCAG 2.2 level AA across the product and publish where we fall short. Three known issues are open right now, all in the chart editor.

Every action has a keyboard path

Including drag-and-drop, which has an explicit move dialog behind the same shortcut.

Named, announced, in order

Landmarks, live regions for async updates, and no icon-only control without a label.

Contrast checked in CI

4.5:1 for text and 3:1 for interface elements, enforced on every pull request.

Motion is optional

Reduced-motion preferences remove transitions and auto-advancing carousels entirely.

Captions and transcripts

Every tutorial video ships with human-checked captions and a full transcript.

Text scales to 200%

Layouts reflow rather than clip, and nothing depends on a fixed pixel height.
