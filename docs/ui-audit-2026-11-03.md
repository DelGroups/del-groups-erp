# UI audit, 2026-11-03/04 (UI-5)

How it was done: the live site (erp.del-groups.com, UI_STANDARD on) was opened with the test
account, **view only** (no save, submit, post, pay or delete). Ten pages were screenshotted at 1440,
1280, 1366x768, 768 and 360x740, and `scripts/ui-page-checks.mjs` measured each one (vertical scroll
containers, page side-scroll, empty band under the content, actions column, numeric alignment,
clipped popovers). Fixes were made and tested locally on `saas/ui-ux-audit`; nothing was changed
on the live site.

Severity: **high** = breaks a task or hides data; **medium** = visibly wrong or inconsistent, task
still possible; **low** = polish.
Status: **fixed** = fixed on this branch (goes live when the PR merges); **open** = left for later.

## Pages opened on the live site

| Page | Problem | Severity | Fix | Status |
|---|---|---|---|---|
| All 10 pages | A second vertical scroller inside the shell (`div.min-h-0.flex-1`); on Sales the grid scrolled on its own as well, on Customers and Products three scrollers were nested. Mouse wheel and sticky headers behaved differently per page. | high | One scroll root (`[data-scroll-root]`) in the shell; page wrappers lost `overflow-y-auto`; grid header and totals stick inside the one scroller. | fixed |
| Sales, Purchases, Imports, view-engine lists | Row "…" menu missing in the view engine; actions column could scroll out of sight. | high | `rowActions` through `ViewEngine`/`EngineScreen` into DataGrid; `RowActionsMenu`; the actions column is pinned. | fixed |
| Dropdowns, lookups, row menus | Clipped by the card or grid around them; z-index values differed per component. | high | One portal layer on `<body>` (`DesignScope`), one z-index scale in `design-system/layers.css`, menus limited to the space available. | fixed |
| Home | Quick actions cut to "Yeni …" (five equal labels). | medium | Full labels ("Satış fakturası yarat" …) in a wrapping grid. | fixed |
| Home | "Customise" was a toolbar row above the cards; the edit tools stayed visible. | medium | Header icon; the edit tools show inside the cards only while editing. | fixed |
| Home | Week comparison numbers ran into each other on narrow cards. | medium | `.ds-wow` table with truncation and a delta chip (expenses: lower is better). | fixed |
| New sales invoice, New purchase | Page title and subtitle near invisible (dark text on the dark header band). Cause: Tailwind 4's `dark:` follows the OS setting, but the app's theme is `data-theme` — with a light OS and a dark app theme every `dark:` style was skipped (14 files). | high | `@custom-variant dark` bound to `data-theme` (graphite and midnight are dark, daylight light). | fixed |
| All pages | Breadcrumbs chained unrelated pages after a typed URL or reload ("Satış › … › Yeni alış fakturası › Imports"). | medium | A page with a fixed address (list, "new" form) starts a new trail; related records still extend it. | fixed |
| Imports, New import, Import detail | Crumb "Imports" in English in az/ru (URL humanised). | medium | Breadcrumb labels for every shell-only page (imports, calendar, to-do, documents, CRM extras). | fixed |
| Customers | Search icon on top of the placeholder text. Cause: `.app-input` padding is unlayered CSS, which always beats Tailwind's `pl-9` (utilities layer). 9 inputs affected. | medium | `.app-input` padding moved into `@layer components`. | fixed |
| Payments | Button "+ + Yeni Ödəniş" (a Plus icon and a "+" in the text). Same in "Yeni tərəfdaş" and the invoice's "Yeni müştəri". | medium | "+" removed from labels that sit next to a Plus icon (az/en/ru). | fixed |
| Products | Record count shown twice ("393 / 393 məhsul göstərilir" and "393 qeyd"). | medium | The grid toolbar shows the page's count; the separate line is hidden with UI_STANDARD. | fixed |
| Sales, Purchases, Payments, Imports (phone) | KPI cards one per row with sparklines: the list started three screens down. | medium | `.ds-kpi-grid`: two per row on a phone; a narrow card drops sparkline and hint. | fixed |
| Status chips | Upper-case, cut at narrow widths. | medium | Sentence case, no truncation in a status cell. | fixed |
| All lists | Numbers sometimes start-aligned, actions sometimes left. | medium | One rule (`columnAlign`): money/number end, actions centre, everything else start. | fixed |
| Imports list | No way to remove a draft. | medium | Delete a draft (type to confirm); prepaid or confirmed imports are cancelled instead (migration `20261103100000_imports_delete_draft.sql`). | fixed |
| Sales (phone) | Ring gauge, chart and top customers stack below the KPIs, so the list is still one screen down. | low | Collapse the analytics row on phones. | open |
| Products | Mixed button colours in one header (blue, pink, outlined green, solid green). | low | Map each to a design-system variant (primary, secondary, danger-outline). | open |

## The rest of the app (through the shared parts)

The other routes were not opened on the live site. They use the same parts, so the fixes above
apply to them:

| Routes | Shared part | Result |
|---|---|---|
| Every page in the new shell or ERPLayout | `NewShell` / `ERPLayout`, `PageContent` | one scroll root |
| Classic lists (customers, suppliers, products, partners, employees, stock, slips, counts, expenses …) | `ListPageChrome` + `ListGrid` + `table-row-actions-menu` | sticky header in the one scroller, row menu, alignment |
| View-engine lists (sales, purchases, contracts, consignments, production, inventory, accounting, imports) | `ViewEngine` / `EngineScreen` / `KpiCards` | row menu, compact KPIs on phones |
| Every form with `app-input` and a leading icon | `globals.css` | icon no longer covers the text |
| Every `dark:` style (14 files) | Tailwind variant | follows the app theme |
| Every page's breadcrumb | `useBreadcrumbTrail` | no chaining after a typed URL |
